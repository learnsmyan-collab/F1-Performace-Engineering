# F1 Performance & Engineering

Hey! Welcome to my Formula 1 performance and engineering project.

If you are interested in racing data analysis and simulation, this is the place where I am trying to make mathematical models which can predict race outcomes for different scenarios.
## What's Inside?

The repo currently focuses on a couple of key performance areas:

* **`Monte carlo race stat/`**: Runs probabilistic race scenarios using Monte Carlo simulations to look at potential outcomes and race stats.
* **`tyre degreation/`**: Focuses on modeling how tires wear down over a race distance so we can better understand pace management and pit stop strategies.
